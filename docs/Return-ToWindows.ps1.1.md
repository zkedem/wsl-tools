# NAME

Return-ToWindows.ps1 - Returns to the Windows desktop

# SYNOPSIS

**Return-ToWindows.ps1**

# DESCRIPTION

**Return-ToWindows.ps1** is a Windows PowerShell script that minimizes
the X session in the foreground and restores focus to the Windows
desktop. To return to the X session, you can select its icon on the
Windows taskbar.

wsl-tools also places a desktop entry for **Return-ToWindows.ps1** under
the **System** category named “Return to Windows”, which can be accessed
from your desktop environment to easily switch between Windows and your
X session.
